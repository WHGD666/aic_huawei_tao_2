# 演化假设库 —— 两种基线的损失 / 解码函数改法（含公式与伪代码）

> 用途：① 作为 harness 提示词里"探针菜单 / 结构阶段指引 / 知识块"的素材来源；② 拿到任务包后按真实签名逐条核对可行性（每条标注了"需要的输入"和"边级退化形式"）。
> 记号：节点 i 面积 a_i，宏指示 m_i∈{0,1}；网（超边）n 的节点集 S_n；2D 时序特征：slack s_i、slew、AT/RAT、cell delay、timing coverage；**所有时序量先做算例内相对化**：q_i = rank(s_i)/(N−1)∈[0,1]（q 小 = 更关键），关键度 c_i = (1−q_i)^β 或 c_i = softplus(−ŝ_i)，ŝ 为算例内 z-score。严禁绝对阈值（ng45 是 ns、asap7 是 ps，规模也差一个量级）。

---

## 0. 基线的样子（按题面推断，待任务包核实）

### 基线 B（概率预测）

GNN 输出 p_i = P(节点 i 在上层)。初始损失大致为

```
L = L_cut + λ_bal · L_bal + λ_bin · L_bin
L_cut = Σ_n [ 1 − Π_{i∈S_n} p_i − Π_{i∈S_n} (1−p_i) ]        # 网被割的概率
L_bal = ( Σ_i a_i p_i / Σ_i a_i − 0.5 )²                      # 上层面积占比
L_bin = Σ_i p_i (1 − p_i)   或   熵                            # 二值化
```
固定阈值 0.5 出初始切分 → 官方修复程序把面积（47–53%）与宏（45–55%）拉回约束。

**已知弱点**：① L_cut 对高扇出网饱和（|S_n| 大时 Π→0，项恒≈1，梯度≈0）；② L_bal 在 50% 附近是平的（二次项），阈值化后很容易偏到 44%/56%，修复程序大翻特翻；③ 没用任何时序特征；④ 宏没有单独处理。

### 基线 A（表示学习 + 聚类，TP-GNN 思路）

GNN 输出嵌入 z_i；初始损失是 GraphSAGE 式无监督对比：
```
L = Σ_i [ − Σ_{j∈N(i)} log σ(z_i·z_j) − Q · E_{k~P_neg} log σ(−z_i·z_k) ]
```
解码：面积加权的两路聚类（weighted k-means，簇大小按面积平衡）→ 离散切分。

**已知弱点**：① 正样本权重一律为 1，关键网和普通网一样；② 聚类只看嵌入距离与面积，割网数与时序都不在解码目标里；③ 平衡修复按嵌入距离翻节点，可能翻走关键节点。

## 1. 基线 B 假设（只改损失）

每条格式：**机制 / 公式 / 需要的输入 / 预期 / 风险 / 边级退化**。

### B1 关键性加权割网（题面点名的方向）
- 公式：`L_cut = Σ_n w_n · cut_n`，`w_n = 1 + α · c_n`，`c_n = max_{i∈S_n} c_i`（网关键度 = 最关键引脚）或 `mean`。α∈[1,5]。
- 需要：网→节点关系（超图）、节点 slack。
- 预期：关键路径跨层次数↓ → WNS/TNS 同向改善；割网总数可能略↑。
- 风险：2D 关键 ≠ 3D 关键；α 太大导致非关键区域乱割、线长↑反而拖累 TNS。
- 边级退化：若只有 `edge_index` + `edge_weight`，`w_e = 1 + α·max(c_i, c_j)` 乘到 `(p_i − p_j)²` 上。

### B2 平衡 hinge（建议所有候选默认带上）
- 公式：`r = Σ a_i p_i / Σ a_i`；`L_bal = λ · max(0, |r − 0.5| − δ)²`，δ≈0.005–0.01，λ 大（≥10）；或 `L_bal = λ·(r−0.5)² + λ₂·max(0,|r−0.5|−δ)`。
- 需要：面积。
- 预期：阈值化后已经在 49–51%，修复程序几乎不动，损失学到的结构得以保留；种子方差↓。
- 风险：λ 过大压制 cut 项；要与 L_bin 配合（p 不二值化时 r 的估计失真 → 可以用 `r` 的硬化版本 `Σ a_i·σ(k(p_i−0.5))` 近似阈值后的占比）。
- 边级退化：无需。

### B3 宏显式平衡
- 公式：`r_m,cnt = Σ m_i p_i / Σ m_i`，`r_m,area = Σ m_i a_i p_i / Σ m_i a_i`；两者各加 hinge（δ≈0.02，约束是 45–55%）。
- 需要：宏指示（特征里的面积/尺寸可推，或任务包直接给）。
- 预期：修复程序不再强行翻宏 → 宏周围标准单元结构保留。
- 风险：宏数很少（bp_fe 8 个）时占比离散，45–55% 可能无解（奇数宏），只能靠面积占比；要容忍。

### B4 关键单元层偏好（**条件假设，需先核实流程不对称**）
- 背景：Open3DBench 公开仓库默认 `DONT_USE_CELLS` 禁用上层的缓冲器单元，时序修复只能在下层插缓冲器。若官方流程保留，则关键逻辑在下层更易修。
- 公式：`L_pref = μ · Σ_i c_i · p_i`（p = 上层概率，把关键推向下层）；与 B2 冲突时由 B7 的"关键面积平衡"缓和。
- 预期：若不对称成立，TNS 明显改善；若不成立，无效或轻微负。**探针阶段第一批测**。
- 风险：集中关键单元到一层会拉长该层线长。

### B5 路径跨层惩罚（拉普拉斯式）
- 公式：对有向时序弧 (i→j)（来自网连接 + 驱动/负载方向，或无向邻接）：`L_path = ν · Σ_{(i,j)} c_i c_j (p_i − p_j)²`。
- 需要：邻接；节点关键度。
- 预期：关键路径整段同层；比 B1 更直接地减少"关键路径上的跨层次数"。
- 风险：与 B1 高度相关，组合时系数要缩。

### B6 归一化割（防退化、改善梯度）
- 公式：`L_ncut = cut(U,B)·(1/vol(U) + 1/vol(B))`，vol 用面积或度；或 `cut / (r(1−r))`。
- 预期：替代 B2 的部分作用；在 p 接近单边时梯度更健康。

### B7 关键面积平衡
- 公式：`r_c = Σ a_i c_i p_i / Σ a_i c_i`；hinge 到 0.5±δ_c（δ_c≈0.05，软）。
- 预期：避免所有关键逻辑挤在一层造成该层拥塞与长线。与 B4 对冲，二者只能选一个方向或用 δ_c 调和。

### B8 二值化形态与退火
- 公式：`L_bin = Σ p_i(1−p_i)` → `Σ H(p_i)`；或系数随 epoch 从 0 升到 λ_bin（若损失函数能拿到 epoch / step，否则不可做）。
- 预期：避免过早锁死；对种子方差有影响。
- 风险："训练预算固定"——若接口没有 step 信息，只能改静态形式。

### B9 高扇出网的割概率形式
- 问题：`1 − Πp − Π(1−p)` 在 |S_n|≥10 时恒≈1。
- 替代：(a) 星型展开 `Σ_{i∈S_n} (p_i − p̄_n)²`，p̄_n 为网内均值；(b) 软极差 `softmax_i p_i − softmin_i p_i`（logsumexp，温度 τ）；(c) 团展开 `1/(|S_n|−1) Σ_{i<j} (p_i−p_j)²`；(d) 扇出 > K 的网直接降权 `w_n /= log(|S_n|)`（时钟/复位网不应主导）。
- 预期：梯度回到大网上，整体割网数↓，线长↓ → TNS 改善；这是与时序无关但很可能最稳的改动。

### B10 时序特征的其它用法
- slew / cell delay 大的节点 → 驱动能力弱 → 更不该跨层（HBT 负载）：`c_i` 里加入 slew 分位数。
- timing coverage（节点被多少条受约束路径覆盖）→ 作为 c_i 的乘子。

### B11 TNS 导向的加权（评分 60% TNS + 同分比 TNS）
- 用"违例端点数量"而非"最差 slack"思维：`c_i` 用 `(−ŝ_i)_+` 的平方根（压缩极端值），让大量中等违例路径都获得权重，而不是只盯最差的一条。

## 2. 基线 A 假设

### 2.1 损失侧

#### A1 关键性加权正样本
- `L = Σ_i [ − Σ_{j∈N(i)} w_ij log σ(z_i·z_j) − Q·E log σ(−z_i·z_k) ]`，`w_ij = 1 + α·max(c_i,c_j)` 或按共享网关键度。
- 需要：邻接 + 节点关键度（基线特征里已有）。

#### A2 时序路径正样本
- 把"同一关键路径上相隔 ≤2 跳的节点"也当正样本（在损失内部通过 2 跳邻接 × c 构造），让关键路径整段嵌入靠近。
- 需要：邻接矩阵可在损失内做一次稀疏乘法。

#### A3 正样本按网扇出归一化
- `w_ij /= Σ_{n∋i,j} 1/(|S_n|−1)`（团展开权重），避免高扇出网把所有节点拉成一团。

#### A4 温度 / 负样本数 / margin
- `σ(z_i·z_j/τ)`；负样本项权重 Q；或改 triplet margin 形式。纯系数探针。

#### A5 特征重构 / 保持项
- `+ η·‖Dec(z_i) − x_i‖²` 需要解码器参数 → 多半不在允许范围（"网络结构固定"）；退化：`+ η·‖z_i − P x_i‖²` 用固定随机投影 P，保留时序特征信息到嵌入。

### 2.2 解码侧（确定性算法，可能是本基线最大的杠杆）

> 前提两条（`open_questions` #2、#17）：解码签名能拿到什么（嵌入 + 面积？还有超图 / 宏指示 / 关键度？）；解码输出之后**是否还有官方修复程序**。若没有修复，解码必须自行保证 47–53% / 45–55%，否则候选无效——gate 要做硬平衡检查，D1/D2/D3 都要以"可行性优先"写。

#### D0 面积加权 k-means（基线）→ 平衡感知初始化
- 用嵌入第一主成分（或 2-means）排序后按面积累积到 50% 处切；比 k-means 更稳、天然平衡。

#### D1 关键性加权 FM 细化（**若解码签名能拿到超图**）
```
init: 由聚类得到 part[i]
gain(i) = Σ_{n∋i} w_n · [ cut_n 翻转后的变化 ]      # w_n 来自 B1 的定义
repeat ≤ T passes:
  bucket by gain; 逐个翻最大 gain 的、且翻后面积占比仍在 [0.5−δ, 0.5+δ] 内、宏占比仍在 [0.45+ε, 0.55−ε] 内的节点
  lock 已翻节点；记录 pass 内最优前缀；回滚到最优前缀
```
- 需要：网→节点、面积、宏指示、关键度。这是经典、确定性、可解释的，LLM 写 FM 的出错率不低但 gate 可本地验证。

#### D2 平衡修复的优先级
- 基线按嵌入距离翻；改为按 `(距簇中心距离) / (1 + α c_i)` 或按 `gain` 翻：先翻低关键、低度、小面积的节点。

#### D3 宏优先
- 先在嵌入空间对宏做满足 45–55% 的二分（宏少，可穷举 / 贪心），固定后再分配标准单元；避免修复程序乱翻宏。

#### D4 关键单元层偏好（对应 B4，条件假设）
- 关键簇与下层对齐：选"关键度总和更大"的簇作下层。

#### D5 多种子聚类取共识
- k-means 多次初始化取割最小者（解码内部的随机数需用传入的 seed，保持可复现）。

## 3. 组合建议（C 阶段）

- 默认骨架：B2（或 D1 的平衡约束）+ B9（大网形式）—— 与时序无关、稳健；在此之上叠一个时序机制（B1 / B5 / B4 三选一，由探针决定）。
- 不要同时上 B4 与 B7（方向相反）。
- A 基线：A1 + D1 是"损失和解码都用关键度"的闭环；A1 + D2 是保守版。

## 4. 探针阶段顺序（5 次评估）

1. B9（大网形式）—— 与时序无关，最可能单独正收益，同时校验"割网数↓ 是否对应 TNS↓"
2. B2（平衡 hinge）—— 校验"修复程序翻动量"与结果的关系
3. B1（关键加权割）—— 校验 2D 关键性是否迁移到 3D
4. B4（层偏好）—— 校验流程不对称
5. B3（宏平衡）或 B5（路径惩罚）
每个探针从基线出发单独改一处，harness 在本地代理层记录：割网数、关键割网数、平衡偏差、修复翻动量、种子一致性，与真实 WNS/TNS 一起写进历史摘要。

## 5. 代理指标定义（本地可算、不花评估）

| 指标 | 定义 | 用途 |
|---|---|---|
| cut | 被割网数 | 结构健康 |
| wcut | Σ_n w_n·[割] （w 按 B1） | 关键性 |
| crit_cross | 关键节点（q<0.1）的相邻对里跨层的比例 | 路径跨层 |
| bal_dev | 阈值化后上层面积占比 − 0.5 | 修复前偏差 |
| repair_flips | 修复程序翻动的节点数 / N | 结构保留度 |
| macro_dev | 宏数量 / 面积占比偏差 | 约束 |
| seed_agree | 三种子切分两两一致率（对齐标签后） | 稳定性 |
| hamming_base / hamming_parent | 与基线 / 父代切分的差异比例 | 去重 / "改动是否真的改变了结果" |
| train_time | 训练 + 解码耗时 | 超时风险 |

与真实得分的秩相关在运行中持续更新并写入历史摘要，供 LLM 判断方向；**不做为排名依据**。
