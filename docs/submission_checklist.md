## 合规自检

- [ ] 候选代码不含算例名 / 规模分支 / 绝对单位阈值
- [ ] 候选只改开放函数；AST 对比通过
- [ ] 最终候选在 harness 可见的 3 训练算例 × 3 种子全部有效（无剔除）；**并且**对未见算例做了防御（无宏块、规模差异、特征单位/分布差异、度为 0 节点、空网）——验证/隐藏算例上任一种子失败同样使最终候选无效，而 harness 看不见
- [ ] 正式运行无人工干预（run.sh 一键到底；logs 可证明）
- [ ] 所有 LLM 调用经官方代理、模型为指定 DeepSeek-V4.1-Flash（logs 里记录 model 字段）
- [ ] 评估次数 ≤ 30、费用 ≤ 15 元（budget.json）
- [ ] 外部资源（Open3DBench、TP-GNN 论文、OpenROAD、DREAMPlace、AlphaEvolve/DGM 思路）在报告中注明版本、使用位置、许可证
- [ ] `.env` / API key 未打包
- [ ] 提交的那一轮是多轮里最稳健的一轮（提交的算法/结果可能用于初步成绩筛选；正式分数来自组委会复跑）
